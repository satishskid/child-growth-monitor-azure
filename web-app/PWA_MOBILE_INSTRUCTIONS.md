# Child Growth Monitor PWA - Mobile Installation Guide

## 📱 Downloadable PWA Package

**File**: `child-growth-monitor-pwa.zip`
**Size**: ~50KB (lightweight and fast)

## 🚀 Installation Steps

### Option 1: Direct File Transfer
1. **Download** the `child-growth-monitor-pwa.zip` file
2. **Transfer** to your mobile device via:
   - Email attachment
   - Cloud storage (Google Drive, Dropbox)
   - USB cable transfer
   - AirDrop (iOS) or Nearby Share (Android)

### Option 2: Extract and Run
1. **Extract** the ZIP file on any device
2. **Open** the `index.html` file in any web browser
3. **Install** as PWA when prompted ("Add to Home Screen")

## 📋 What's Included

```
dist/
├── index.html          # Main PWA application
├── manifest.json       # PWA configuration
├── service-worker.js   # Offline functionality
└── icons/             # App icons for installation
    ├── icon-192x192.png
    └── icon-512x512.png
```

## ✅ Features Available Offline

- **Mass Screening Interface** - Child lookup and data entry
- **Batch Upload System** - CSV/Excel file processing
- **QR Code Generation** - Unique ID system for children
- **Data Export** - Save and share collected data
- **Offline Storage** - Works without internet connection
- **Mobile Optimized** - Touch-friendly interface

## 🔧 Usage Instructions

1. **Open** `index.html` in mobile browser
2. **Tap** "Add to Home Screen" when prompted
3. **Launch** from home screen like a native app
4. **Import** child data via CSV/Excel files
5. **Conduct** mass screening sessions offline
6. **Export** data when ready to share

## 📱 Compatible Devices

- **iOS**: Safari, Chrome, Firefox
- **Android**: Chrome, Firefox, Samsung Internet
- **Desktop**: All modern browsers

## 🆘 Troubleshooting

**Issue**: PWA won't install
**Solution**: Ensure you're using HTTPS or localhost

**Issue**: Files won't upload
**Solution**: Check file format (CSV/Excel supported)

**Issue**: Data not saving
**Solution**: Allow storage permissions in browser
